## Local development

```bash
npm install
npm run dev
```

Run `npm run typecheck` and `npm run build` for production verification. The separate RiskOps AI repository scaffold is under [`riskops-ai`](riskops-ai/README.md).

## Evidence policy

- Do not publish an internal architecture claim until it is supported by code or deployment configuration.
- Do not publish a metric without a reproducible artifact, scope, and date.
- Do not link a private repository without explicit authorization.
- Do not use customer records, credentials, private prompts, or confidential infrastructure in screenshots and diagrams.
